# B3 BMW technical and evidence sources

Checked 28 September 2026. Manufacturer material supports cautious system descriptions and vehicle-specific qualifications. It does **not** independently verify DIGI-TEC equipment, a particular employee's qualification, the workshop's access permissions, or acceptance of every BMW repair.

## Manufacturer and component-maker evidence

| Source | Supported point | B3 boundary |
| --- | --- | --- |
| [BMW Group technical-information guide](https://bmwtechinfo.bmwgroup.com/assets/system_requirements.pdf) | BMW's independent-workshop information describes ISTA diagnosis, test plans, service information and generation-dependent programming applications. | ISTA+ is a diagnostic capability, not a promise that every code identifies a failed component or every function is available on every vehicle. Coding and programming remain separate, vehicle/module-dependent tasks. |
| [BMW Group technical-information site](https://bmwtechinfo.bmwgroup.com/tisUI/?oss_module=AIR) | Access to technical information and diagnostic/programming resources has its own registration and requirements. | A tool name does not establish manufacturer authorization or unrestricted security access. |
| [BMW Condition Based Service explanation](https://www.bmw.com/en-au/offers-and-services/personal-services/bmw-teleService.html) | The vehicle's Condition Based Service information indicates relevant service needs. | No fixed oil grade or one BMW-wide interval was inferred. The exact model, engine, year, history and applicable vehicle information govern the plan. |
| [ZF 8HP oil-change service information](https://aftermarket.zf.com/app/controller/ti/download/Binary/22f16dae-c571-11ec-a2e7-00505690da53.pdf) | ZF's procedure requires transmission identification, prescribed fluid and temperature-controlled fill steps. | B3 does not state all BMWs have an 8HP, nor that a fluid change cures a shifting fault. |
| [BMW xDrive description](https://www.bmw.com/en-au/offers-and-services/bmw-special-sales/bmw-authority-vehicles.html) | xDrive is BMW all-wheel-drive technology. | xDrive fault assessment is not automatically a transmission repair; fitted hardware and control inputs need diagnosis. |
| [BMW Group technical training: battery/power management](https://bmwtechinfo.bmwgroup.com/tech_training_manual/ST1212%20F01-F02%20Life%20Cycle%20Impulse.pdf) | Battery type, state-of-charge data and power management vary by vehicle architecture. | A battery warning does not prove replacement, and registration/coding is confirmed for the exact vehicle. |
| [BMW ConnectedDrive and operating-system overview](https://www.bmw.com/en-au/offers-and-services/bmw-connected-drive/bmw-connected-drive-overview.html) | iDrive and display functions depend on the vehicle's operating system and fitted equipment. | A black screen is assessed before a head-unit replacement or upgrade is proposed. |

The regional BMW and ZF sources explain technical principles; the applicable VIN-specific information controls any real service procedure. No claims of BMW authorization, certification, fixed repair success, failure frequency, warranty, price or universal programming access were derived from them.
