# Nine model page architectures

All pages keep the shared DIGITEC identity, source package tables, model FAQs, GAD project assessment and model-specific enquiry. The sequence below follows the hero and local navigation.

| Model | Concept | Content order | Engineering emphasis |
| --- | --- | --- | --- |
| Mercedes-AMG GT / GTS / GTC / GTR | Sports-Car Performance | platform → engineering → selector → packages → guide | Two distinct variant records; Gearbox work enters at Stage 2; Turbo and engine progression |
| Mercedes-AMG E63 | Performance Engineering | platform → engineering → selector → guide → packages | ECU and CPC scope; Different turbocharger packages; Transmission integration |
| Mercedes-AMG G63 | Power & Capability | selector → platform → engineering → packages → guide | Stage 1 engine and CPC work; G63-specific exhaust scope; Higher-stage drivetrain planning |
| Mercedes-AMG GT63 4-Door | Digital Performance Dashboard | selector → engineering → platform → packages → guide | Four-door model identification; Software and exhaust progression; Turbo, fuel and gearbox work |
| Mercedes-AMG S65 | V12 Luxury Engineering | engineering → platform → selector → guide → packages | PCM and TCU at Stage 2; NAG2 reinforcement progression; Cooling work appears explicitly |
| Mercedes-AMG C63 (W205) | Stage Comparison & Upgrade Guide | platform → selector → guide → engineering → packages | W205 compatibility first; ECU versus transmission work; Hardware changes between stages |
| Mercedes-AMG GLC63 | Performance Upgrade Advisor | guide → platform → selector → engineering → packages | Engine and platform check; Stage 1 and Stage 2 scope; Transmission price alternatives |
| Aston Martin DB11 | Grand Touring Performance | engineering → platform → guide → selector → packages | A specific V8 record; Transmission software is listed; Higher-stage supporting components |
| Lamborghini Urus | Super-SUV Performance | platform → selector → engineering → packages → guide | Stage 1 is engine software; Turbo upgrade with installation kit; Intercooler at Stage 4 |

`platform`: engine and generation compatibility; `selector`: stock versus tuned stage advisor; `engineering`: model-specific software/hardware integration; `guide`: upgrade planning; `packages`: complete source specification, price and time tables.

Existing model cutouts are reused. S65 uses a neutral M279/V12 identity panel because no verified S65 photograph is available; its social metadata uses the existing generic tuning image. No generated vehicle/workshop photography or calculated dyno chart is introduced.
