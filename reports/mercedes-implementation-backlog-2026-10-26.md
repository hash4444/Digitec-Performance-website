## Approval and acceptance package

For any later implementation, prepare the exact proposed diff, URL list, current production baselines, protected regression matrix, validation and rollback procedure for the user to review. Do not run a build or deployment merely to execute this planning backlog. Cloudflare rules must remain untouched unless a later instruction explicitly authorizes a specific change; the current task explicitly prohibits it.

Acceptance is measured first by correct relevant responses and qualified inquiries, then by sustained visibility changes in comparable cohorts. A completed ticket is not evidence of a top-three ranking or an attributed booking.
